Provenance note (added at release, v0.1.0).

This file is the original project brief, kept verbatim as the record of what was asked for. It names
the reference product because the brief does; that naming is a factual reference, and it is one of the
places where naming it is expected (see `LEGAL.md`).

What the brief was carried out as, in plain terms: the reference product's *behaviour* was studied to
learn what to build - features, configuration vocabulary, service-discovery type, licensing model - and
VirtualThere was then written independently on the open **USB/IP** standard. No VirtualHere code,
binary, driver, resource or data file is used, copied or redistributed; VirtualThere is not
wire-compatible with it, and is not affiliated with it. The evidence and the reasoning are in
`docs/RECON_AND_SPEC.md` (sections 1 and 9) and the short version in `LEGAL.md`.

The brief's "for free" is implemented as: no licence key, no device cap, no trial state, no purchase
prompt, and no gated verb, ever - see `README.md`.
