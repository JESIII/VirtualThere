# P2 rebind: before/after transcript

Card: `t_6f34fa4d` — "P2 rebind is unreachable: the capture provider bails on IsExportable()
before the rebind block". Landed as commit `2a1fe0e` on `main` (fix) plus `2a1fe0e`'s follow-up
transcript commit. Host: ZUAN, 14 USB devices present, unelevated shell, `elevated=False`.

Every run below is a real process on this machine. The only thing that was *not* run is the
elevated half of P2 (see "NOT RUN" at the end).

The client was a minimal USB/IP `OP_REQ_IMPORT` (op 0x8003) client, the same request a stock
`usbip attach` sends, so this is the real claim path inside `UsbIpSession`. Instead of silence the
server now names the P2 outcome: **the not-elevated refusal**, one of the three outcomes the card
asks for. `exported=14` instead of `0`.

Note the 3240 conflict: a long-running `G:\Repos\VirtualThere\dist\portable\vht.exe` (started
01:16:40 by an earlier run) still owns port 3240, so this run used its own config on 3340. The
first import attempt against 3240 was served by *that* process and refused with `Unknown`.

## 5. The regression tests fail on the pre-fix code

`tests/Vht.Acceptance.Tests/CaptureRebindPathTests.cs`, reverted one half of the fix at a time.

* Provider half reverted (`IsClaimable()` gate → the old `IsExportable()` bail):
  `Failed: 4, Passed: 6` — including
  `DriverHeldDevice_WithRebindEnabled_ReachesTheP2RebindAttempt: Assert.Single() Failure: The collection was empty`
  (the rebinder was never called).
* Enumerator half reverted (`ClassifyOpenFailure` never offers the rebind):
  `Failed: 7, Passed: 3` — including
  `ClassifyOpenFailure_OffersRebindOnlyWhenPermitted_AndNamesTheState: Assert.Equal() Failure: Values differ`
  (`RebindOffered` vs `CaptureUnsupported`).
* Both restored: `Passed: 10, Failed: 0`.

## NOT RUN

* **Elevated rebind (`rebound onto the inbox winusb.sys`, including the reboot-required line).**
  Elevation on this host is an interactive UAC prompt and cannot be answered from an unattended
  run (`docs/ACCEPTANCE.md` §2 records the same limitation). The two elevated outcomes are
  therefore **NOT RUN**, and the not-elevated outcome above stands in as the real, observed P2
  attempt.
